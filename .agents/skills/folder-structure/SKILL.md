# Estructura de Carpetas Ordenada

Este proyecto sigue una organización estricta y profesional. Cuando crees o muevas archivos, respeta esta jerarquía:

*   `assets/css/styles.css` - Archivo único de estilos globales.
*   `assets/js/script.js` - Archivo único de lógica JS.
*   `assets/img/` - Imágenes organizadas. Específicamente:
    *   `assets/img/comidas_varias/` - Fotos generales de comida.
    *   `assets/img/hamburguesas/` - Fotos de su comida favorita.
*   `pages/` - Archivos HTML modulares:
    *   `pages/bienvenida.html`
    *   `pages/recuerdos.html`
    *   `pages/carta.html`
*   `/` (Raíz) - Solo para el `index.html` (redirigente), el archivo `README.md`, `descripcion_proyecto.md` y `GEMINI.md`.

**Regla de Oro:** ¡Ningún archivo suelto en la raíz que no pertenezca ahí! Todo debe ir a su respectiva carpeta semántica.
