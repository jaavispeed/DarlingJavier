# Programación Simple y Directa

Cuando programes para este proyecto, debes seguir estos principios para evitar la sobreingeniería:

1.  **Código Limpio y Legible:** Utiliza nombres de variables descriptivos y comentarios donde sea necesario, sin saturar el código.
2.  **No Frameworks Innecesarios:** Mantén el proyecto en Vanilla JS, HTML puro y CSS clásico a menos que se solicite lo contrario. No agregues librerías pesadas si no hay un caso de uso estricto.
3.  **Soluciones Simples:** Si un problema se puede resolver con 5 líneas de CSS o JS, no escribas 20. Busca la solución más directa.
4.  **Separación de Intereses (SOLID):** Mantén la lógica separada del diseño y la estructura, respetando los principios básicos de desarrollo sin complicar de más la arquitectura.
5.  **100% Responsive y UX:** Cualquier código escrito debe garantizar que las interfaces sean completamente adaptables a móviles y escritorio. La experiencia del usuario (UX) es primordial y siempre debe ir de la mano con la temática mágica y romántica del proyecto.
