# 💜 Proyecto: 3er Aniversario - Darling y Javier

¡Bienvenidos al proyecto web de aniversario! Esta es una página web romántica y personalizada, creada especialmente para celebrar los **3 años juntos** de **Darling** y **Javier** (desde el **30 de agosto del 2023**).

## 📝 Descripción General

Esta página web está diseñada para ser una experiencia interactiva y emotiva. A través de ella, Darling podrá interactuar con diversos elementos para descubrir imágenes y textos sorpresa a medida que navega. Todo el diseño y la estética están pensados para transmitir amor, usando como color principal el morado 💜, el cual tiene un significado especial en la relación.

## ✨ Características Principales

- **Temática de Amor:** Diseño romántico centrado en la celebración del tercer aniversario.
- **Diseño Interactivo:** Elementos con los que el usuario (Darling) puede interactuar para revelar sorpresas de manera progresiva.
- **Recuerdos Gastronómicos:** Secciones dedicadas a momentos especiales compartidos, como "comidas varias" y un espacio destacado para su comida favorita: las hamburguesas 🍔.
- **Sección de Carta Especial:** Un espacio dedicado a una carta interactiva de aniversario.
- **Paleta de Colores Personalizada:** Enfoque principal en tonos morados 💜, aplicados a la interfaz, detalles visuales y elementos gráficos como corazones.
- **Detalle Especial:** Uso exclusivo del sobrenombre "Darling" (en lugar de Fernanda) para hacer la experiencia mucho más íntima y significativa.
- **100% Responsive:** Diseño adaptable para verse perfecto en dispositivos móviles, tablets y computadoras de escritorio.
- **Experiencia de Usuario (UX) Mágica:** Navegación fluida e intuitiva enfocada en una experiencia cálida.
